# Tabi · Переезд 2026

Мобильное веб-приложение для учёта вещей: комнаты, цветовые решения, канбан, завершение, JSON-экспорт/импорт.

## Запуск
Откройте `index.html` в браузере или опубликуйте статический сайт с HTTPS. Для облачной синхронизации используйте отдельный аккаунт Supabase Auth и личный пароль шифрования.

## Приватность
Репозиторий должен быть **Private**. GitHub Pages может публиковать сайт публично даже из приватного репозитория. Публикуемый HTML и публичный ключ Supabase не являются секретными. Никогда не добавляйте в репозиторий пароль БД, `service_role`, `sb_secret_`, пароль учётной записи и пароль шифрования.

## Статус
Это тестовая версия v1.4, требующая проверки входа, двухсторонней синхронизации и поведения при одновременном редактировании. Данные сохраняются локально; делайте резервную копию JSON.
