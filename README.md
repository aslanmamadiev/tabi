# Tabi · 旅

**Tabi** — лёгкое веб-приложение для организации вещей при переезде. Помогает разложить вещи по комнатам, принять решение по каждой из них и отслеживать выполнение — в списке или на канбан-доске.

**Открыть приложение:** https://tabi-axm12.vercel.app/

> Текущий статус: рабочая версия, доступная для небольшого пользовательского тестирования. Проект развивается итеративно.

## Возможности

- **Комнаты и предметы:** добавление, изменение, удаление, поиск и фильтрация; создание предметов непосредственно в комнате.
- **Четыре статуса:** «Оставить», «Не знаю», «Отправить / взять», «Без метки»; отдельно отмечается выполнение для определённых решений.
- **Два представления:** список по комнатам и канбан; групповые действия и управление порядком.
- **Прогресс:** сводные показатели и подсказки о текущем этапе подготовки.
- **Оформление:** светлая **Komorebi**, тёмная **Dusk** и автоматическое следование системной теме.
- **Резервные копии:** экспорт и импорт JSON, восстановление состояния из файла.
- **Синхронизация:** локальная работа в браузере; по желанию — личный аккаунт и облачная синхронизация через Supabase.

## Первый запуск

Откройте приложение по ссылке выше. Новому пользователю предлагаются четыре пустые комнаты: **Гардеробная, Гостиная, Кухня и Ванная**; список предметов пуст. Создайте свои предметы и при необходимости измените комнаты.

Локальные данные сохраняются в конкретном браузере и на конкретном адресе сайта. Для переноса между устройствами можно воспользоваться JSON-копией или настроить личную облачную синхронизацию.

## Хранение и приватность

- **Локально:** данные находятся в хранилище браузера. Его очистка может привести к потере несинхронизированных изменений.
- **В облаке (необязательно):** для синхронизации используется Supabase Auth, разграничение доступа по владельцу записи (RLS) и клиентское шифрование JSON через **PBKDF2 + AES-GCM**.
- **Контроль изменений:** запись из актуального клиента использует серверную проверку версии (CAS). Это снижает риск конфликтной перезаписи, но не гарантирует разрешение всех одновременных изменений.
- **Восстановление:** перед заменой облачного состояния создаётся локально доступная копия прежних данных. Она хранится **без шифрования в браузере** — скачайте её и храните безопасно, если она нужна.
- **Важно:** не передавайте другим людям пароль аккаунта, пароль шифрования и личные JSON-копии. Ссылка на приложение сама по себе не раскрывает ваши вещи.

> Репозиторий публичный; исходный HTML и публичный ключ Supabase доступны посетителям по определению. Секретные ключи (`service_role`, `sb_secret_*`), приватные пароли и пользовательские данные не должны попадать в Git.

## Установка и разработка

Tabi — статическое приложение без обязательной сборки: интерфейс находится в `index.html`.

1. Для просмотра интерфейса откройте `index.html` в браузере.
2. Для работы Web Crypto и облачной синхронизации используйте **HTTPS** (или локальный доверенный контекст).
3. При собственном развёртывании настройте собственный проект Supabase, правила доступа и адрес приложения; не рассчитывайте, что чужая облачная конфигурация подходит для вашего развёртывания.

Изменения сначала проходят через отдельные ветки и проверку Preview, затем переносятся в `main` после тестирования. История и проектные решения — в каталоге [docs](./docs/).

## Иконки и установка на домашний экран

Фирменный знак Tabi — кандзи **旅** («путешествие»), оформленный в палитрах **Komorebi** и **Dusk**.

В ветке `feature/icons-02-pwa` подготовлены настоящие файлы иконок вместо встроенного data-URI: SVG-фавикон, PNG-фавикон для старых браузеров, изображения 192×192 и 512×512, а также два web app manifest. При смене темы приложение обновляет ссылки на соответствующие изображения.

На iPad и iPhone иконку можно проверить через Safari → «Поделиться» → «На экран Домой». На Android — через меню браузера → «Добавить на главный экран» / «Установить приложение». Для корректной проверки старую закладку или ярлык иногда нужно удалить и создать заново.

**Ограничение:** уже установленный ярлык обычно не меняет иконку автоматически при переключении темы; выбранный вариант определяется при добавлении. На некоторых мобильных браузерах фавикон не отображается прямо в адресной строке. Два оформления также доступны для прямого просмотра по `/icons/favicon-light.svg` и `/icons/favicon-dark.svg`.

## Ограничения

Tabi предназначен для персонального использования и небольшого тестирования. Синхронизация требует подключения к сети, учётной записи и правильного пароля шифрования. Прямая запись из старых клиентов пока не полностью отключена на сервере; используйте актуальный сайт. JSON-резервные копии рекомендуются перед важными операциями.
